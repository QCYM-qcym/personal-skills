# 数学知识建模与学习层：审查及实施方案

日期：2026-09-23。修改目标经用户确认是 personal-learning-skill 1.5.0；已安装 Teach 插件仅作为架构辨别参考，不修改其缓存。本文在教学文件修改前形成；不把实施计划当测试结果。

## 1. Repository audit

审查目标主文件、references 全部10份、templates 全部8份，以及仓库 README、AGENTS、CHANGELOG、校验脚本、两份测试、CI 和问题模板。主目录没有独立 prompts/workflows/examples/scripts/schemas/tests；教学流程和提示写在主文件/引用中，概率论示例嵌在 knowledge-modeling，自动检查在仓库 scripts/tests。无教学运行引擎或数据库，不能声称有程序自动执行的学习状态机。

当前入口 → 材料核验与四图 → 最小知识点 → 讲解/回忆/尝试/提示/首错/变式 → 混练/延迟复习 → 精简记录。课程设计负责 HTML、难度调整和代码库入门。知识由共享 ID、关系边、glossary 概念卡及 solve card 表达。评估采用真实作答、变式、混练和闭卷输出；四种节点状态与活动/复习状态分开。独立/延迟证据存 .learning，CURRENT 最后提交并读回。六项个人笔记不是教材替身。

已安装 Teach 使用 MISSION、RESOURCES、learning-records、lessons、reference、NOTES，学习记录是简短洞见，无相同的四状态账本。它与个人 Skill 不同，不能直接按同一路径修改。

## 3. Architecture proposal / implementation plan

Core 保留目标、四图、课程/课件、反馈、存储与复查。只增加一条数学路由及模板可选指针；数学扩展负责知识类型、公式策略、模型/题型识别、数学错误分类、能力维度。科学思维 Skill 不重写、不建立第三套课程状态。

新增三份按需引用：mathematics.md（流程/教学策略）、math-node-format.md（人和 agent 可读的数据契约）、math-examples.md（三领域教学与边界案例）。复用 glossary/solve-cards/maps/learning-records/NODES/REVIEWS，引用而非复制事实。没有稳定自动抽取程序需求，因此不添加假设可靠的 PDF 解析器、图引擎或单独 prompts/workflows 目录；格式规范承担 schema，主文件及引用承担 prompt/workflow。

先写扩展，再接入口与四个已有模板的可选字段，最后同步 README/版本/验证记录。保留 state_schema 1、原路径和未知字段；旧节点缺知识类型时按需补，缺能力维度时保持未知。NODES 是能力唯一依据，事件保存尝试与诊断，图卡只引用。即使切换轻量版也保留未知数学字段，重新进入数学分支再读取。

默认当前目标一个连贯教学单元；已具备前置不重复诊断。地图只更新当前依赖闭包；重要概念从12项理解框架中挑必要项，不逐项盘问。按 session goal 选择解释、公式、刷题、错题、复习或考试模式。

## 4. 验证计划

- 二项分布：抽样机制未知不默认独立；有限总体不放回辨别；公式条件和类型多标签；撤去章节提示。
- 定积分：Riemann 入门范围、连续是可积充分非必要条件；带符号积累与几何面积；换元边界及外部前置。
- 特征值/向量：非零向量、齐次方程与核空间、几何直觉；重根不保证可对角化；实/复域区分。
- 负例：方差加法遗漏协方差、互斥与独立、仅记住公式、CARELESS 无证据、标题泄露方法。
- 兼容：旧节点无数学字段、仅旧“独立通过”不能推成迁移；英语/普通编程不启用；当前题/提示/事件链接跨会话保留。
- 执行现有全部校验，并由未参与编写的助手按新 Skill 实际响应三个数学域及非数学/接续场景；如发现缺口修正再测。区分自动检查、行为抽检、未实测的长期学习效果与真实 PDF/OCR。
