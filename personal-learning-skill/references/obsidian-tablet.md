# 分层知识地图与平板学习

课程阶段与入口遵循 [学习生命周期](learning-lifecycle.md)：新整课先全景，续学恢复，明确题型总结直接交付；本文件提供当前分支细节。

触发：用户需要宏观与细节联动、Obsidian、可展开思维导图，或电脑资料配合平板手写。目录与 Canvas 技术约束沿用 [项目初始化与迁移](project-portability.md)，不要另建一套 CURRENT 或能力记录。

## 1. 三层入口，四种知识视图

三层是缩放粒度；四图是全景、前置、关系、跨学科四个观察角度，两者不互相替代。

| 层级 | 展示与进入方式 | 完成标准 |
| --- | --- | --- |
| 学科全景 | 研究问题、模块、推荐入口；链接模块地图 | 用户能定位当前学习在全局的位置 |
| 模块关系 | 有标签的前置、推导、比较、推广、应用边；链接概念文件 | 至少可解释当前节点的一条纵向联系与一条有依据的横向联系；不存在则说明缺口 |
| 节点详情 | 按 [概念卡模板](../templates/concept-card.md) 展示本质、条件、例子反例及关键推导 | 能从图进入详情、从详情返回地图和来源，验证任务与答案分开 |

在 Obsidian 中，Markdown 是概念内容的唯一维护位置，Canvas 使用引用这些文件的卡片，避免把全文复制进多个白板。图上只保留短摘要；通过点击文件/标题进入细节实现逐层展开，不承诺原生 Canvas 自动提供语义缩放或折叠所有分支。全局 Graph 可辅助发现链接，关系含义仍由边标签或关系表明确。

先检查已有笔记目录并沿用命名。新项目采用 [课程设计](course-design.md) 的工作区，概念卡放 glossary/，手写练习及附件按需保存在 practice/、assets/；已有 concepts/ 可继续沿用。有内容才建文件。方法总结在必要基础讲完后按用户目标建立，不一开始生成全课程题型库。地图和参考卡由 AI 草拟并标来源；用户审核关键联系与解释，不承担搬运文本的工作。

交付时检查：实际文件链接可解析、全景到当前节点有路可走、详情有返回入口、关系边含义清楚、同一概念无重复权威副本。新增图只展示已有证据，不虚构用户掌握状态。

## 2. 电脑与平板分工

电脑端负责资料定位、地图、参考卡、方法索引与复查队列。平板负责手写推导、画解释图、闭卷重建、做题和纠错；不默认让用户逐字重写电脑内容。

先读取个人设置，不重复询问已知设备。用户当前选择华为自带笔记作为手写主工作区，Obsidian 只承担导航与关联，因此默认采用下面的文件往返路线，无需在平板安装 Obsidian。具体机型、系统、App 版本、是否需离线及已有传输方式只在实际导入导出时补问。缺信息不阻塞学习：先给 Markdown 学习页，不默认购买软件或安装插件。

两条可选路线：

- 平板也使用 Obsidian：通过已选且验证可用的同步方式访问同一知识库；先用一条笔记和一个附件验证两端可见，再宣称已同步。笔迹输入能力依赖具体工具，不能把 Canvas 的连接线当作手写功能。
- 平板使用手写笔记软件：电脑保留主知识库，仅把当前单元学习页导出为软件支持的 PDF 等格式供书写。PDF 是某一版本快照，不能保证保留可展开地图、双链或双向编辑；学习页印节点 ID、日期与版本。原生手写文件留在原软件，按需导出 PDF/图片回流。

仅修改 Skill 不代表已创建知识库、生成 PDF 或配置同步。实际生成 PDF 时按可用的文档工具完成渲染检查；没有导出能力则交付源文件并明确限制。

## 3. 每个单元的闭环

1. 从全景找到当前模块，读概念卡与一个完整解释示例；短讲保持连贯，避免单句确认。
2. 生成 [平板学习页](../templates/tablet-session.md)：按当前目标选择概念解释、关系重建或独立尝试，可合并为一题，不强制每次各做一项，留手写空间；题目不附原题答案。
3. 用户关掉对应解释页，在平板用自己的语言重建含义、条件和连接，并完成尝试。所需帮助按主 Skill 提示阶梯提供。
4. 对照或提交作答后定位首错；看过答案的补写标为订正，不算独立通过。
5. 按“日期 + 节点 ID”保存必要的手写 PDF/图片。只把新误解、修正和复查任务提炼回六项笔记，附原手写文件链接；沿用 CURRENT 更新证据，避免双端重复誊写。

## 4. 判断是否更有效率

不承诺换设备就能“快很多”。记录学习时间、整理/传输时间、独立变式表现及延迟闭卷表现，用相近难度单元试用后比较。若排版、同步和抄写挤占练习时间，缩减文件数量与导出频率。

[Blunt 与 Karpicke 的实验](https://learninglab.psych.purdue.edu/downloads/2014/2014_Blunt_Karpicke_JEDP.pdf)发现，闭卷提取无论采用段落还是概念图形式，都能优于继续研读，两个提取形式没有显著差异。这支持把地图用于回忆任务；它没有检验本用户的设备组合，也不能证明平板更快。

功能依据：[Obsidian Canvas](https://obsidian.md/help/plugins/canvas)、[跨设备同步](https://obsidian.md/help/sync-notes)、[文件嵌入](https://obsidian.md/help/embeds)。选择工具或配置时核对实际版本与可用能力。

华为官方的 [分享和导出笔记](https://consumer.huawei.com/cn/support/content/zh-cn16071035/)列出适用产品及图片/PDF等导出形式；这不证明用户当前设备支持全部格式，也不代表 Obsidian 双链能在华为笔记里使用。先用一张学习页验证导入、手写、导出和电脑关联；若不支持 PDF 导入，按实际支持的图片或新建空白笔记完成同样的任务。
