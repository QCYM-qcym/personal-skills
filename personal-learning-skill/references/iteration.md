# 修改与回归检查

仅在调整偏好、更新学习方法或复核 Skill 时阅读。版本以 SKILL.md 的 metadata.version 为准；下面的记录保存修改理由。

## 修改位置

- 时间、间隔、提示偏好、输出格式：修改用户自己的个人设置副本。
- 通用辅导顺序与约束：修改 SKILL.md。
- 节点、关系、四图规则：修改 knowledge-modeling.md。
- 笔记字段：修改 study-record.md；已有记录保留，缺字段按需补。

修改循环：收集一次具体失败 → 区分“材料/基础问题”与“方法问题” → 只改一个关键规则 → 在相近任务中试用 → 比较独立完成、所需提示、延迟提取和负担 → 保留或回退。不要以更长的笔记或更多的图作为改进证据。

用户明确要求的修改直接落实；AI 自行提出的长期偏好调整先作为建议，不静默覆盖。语义澄清升补丁版本，兼容新增升次版本，流程或记录结构不兼容升主版本。改节点名称时保留 ID 或记录别名。

## 可复用的行为验收场景

### 1.4.0 — 2026-09-20

按用户要求统一新课程工作区（mission/resources/HTML lessons/glossary/solve-cards/notes），说明 HTML 的交互与图解职责，加入最近发展区的证据校准、进度报告后诊断并定做下一课、代码库 onboarding 分支。保留原状态协议 schema 1，旧目录按职责映射而不搬迁。新增课次与支架可选字段，不重置历史。

新增验收：用户只说“看完”时先诊断；太难时补支架而不连续升提示；旧 MISSION 正文与新 mission 指针不双写；HTML 结果未回传不能自动认定已保存；代码库教学按真实调用路径而非文件名猜测；限制为只读时不直接实施改动。

### 1.3.0 — 2026-09-20

从仅约定 CURRENT 的接续方式，升级为课程级状态协议 v1：新增节点与复查账本、事件先写与修订号最后提交、恢复及迁移规则。保留 1.2.0 的概念优先、三层地图和华为笔记偏好。技能只定义流程与模板，实际状态由有文件能力的助手保存，不提供自动后台记忆。

新增验收：换会话恢复准确题目；提示后的成功不算独立；暂停不丢失卡点；更换课程不继承能力；写入失败不给虚假保存确认；旧记录/未知字段保留；重复事件不重复入队；高版本 schema 不降级覆盖。

修改后用未参与编写的助手实际响应，检查行为而不只检查是否背出规则。

| 输入场景 | 可观察的合格表现 |
| --- | --- |
| 只有概率论目录、PDF 未上传，今天仅 20 分钟 | 标材料缺口，先给四种简图与入口诊断；不虚构页码，不因时间少跳过建模 |
| 给出包含 P(A\|B)=P(B\|A) 的错误步骤 | 定位首处等式，给一个最小提示并等待；不当场给完解法 |
| 同类题连续做对，要求记笔记和安排下一步 | 保留六项笔记，要求变式、混合与延迟闭卷证据；不直接标掌握 |
| 扫描 PDF 公式模糊、正文只有局部可读 | 列已读范围与待核验处，仅基于可见材料建临时图 |
| 用户明确说本轮要完整讲解 | 尊重本轮选择，不把它写成永久放弃主动尝试 |
| 用户只要翻译 PDF 中的一段话 | 完成翻译，不强制建立四图或开设学习课程 |
| 用户说把复习间隔改成 2、5、10 天 | 修改个人设置，不同时改笔记结构或覆盖旧掌握证据 |

每次测试记录输入、实际回复、观察到的偏差与修正。检查相对链接、YAML、版本和压缩包内容只能证明包装可用，不能证明教学效果。
