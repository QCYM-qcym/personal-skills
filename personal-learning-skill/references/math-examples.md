# 数学层三领域示例与验收

以下为原创通用教学示例，不来自用户 PDF，不表示用户已学会；教材引用需实际读取后补。维护检查时使用，日常只读相关例子。ID 为演示，接入课程优先已有 ID。

## A. 概率论：二项分布

节点 binomial：Concept / Mathematical Model / Formula / Problem Pattern。前置为事件、独立性、Bernoulli 试验和组合计数；这些节点 used_by binomial；二项均值公式 derives_from 指示变量和期望线性。分布、均值、方差分别有条件，不把独立设成期望线性的一般前提。

模型：固定 n 个独立、同成功率 p 的二元试验，X 为成功次数；n 为非负整数，0≤p≤1，k=0,…,n。公式 P(X=k)=C(n,k)p^k(1-p)^(n-k)，端点 p=0或1按退化分布理解，避免直接处理0^0歧义。公式为模型下推导结果；理解条件 MUST_UNDERSTAND，组合推导 SHOULD_DERIVE，是否背诵结合目标，低频扩展可查询。

模式：固定机会数的成功计数；先抽对象/次数/成功定义/独立及恒定率证据，再定模型。首选按成功次数计数；“至少一次”可选补事件；若固定有限总体不放回，独立依据失效，可能应使用超几何模型。

验收输入：“某产品次品率2%，随机抽100件，次品数就是二项分布吗？”合格：指出仅有这些信息不足以保证独立恒定率；区分抽样机制与近似条件，不直接套式。“100件中恰有2件次品，全部取走”时计数恒为2，不能当 Bin(100,.02)。没有观测步骤前不给用户贴模型识别错误标签。

错误例：因“只有两种结果”就选二项。首错→MODEL_RECOGNITION_ERROR/CONDITION_MISSED→独立/恒定率节点→比较两种抽样结构→新情境再测。去标签题不在标题写“二项分布练习”，计算正确但方法已揭示只支持执行维度。

## B. 高等数学：定积分

节点 definite-integral：Concept / Formula；关联定理节点 FTC 为 Property/Theorem，换元节点为 Method/Strategy。入门采用闭区间 Riemann 积分，定义来自带标签分割和的极限；前置为函数、有限和、极限。导数不必是定义定积分的前置，但通过原函数计算的路线依赖导数和微积分基本定理。

性质例：IF f 在[a,b]连续且 F'=f THEN 积分等于F(b)-F(a)。连续是Riemann可积的充分而非必要条件，例如有限跳跃的阶梯函数仍可积。推导公式和定理条件绑在一起；不能对跨越奇点的1/x直接套原函数差值，而忽略反常积分是否存在。

含义：带符号积累；定积分不总是几何面积。对 f(x)=x 在[-1,1]，积分为0而图形与轴间总面积为1。用户声称“积分为0说明函数处处为0”时，先查符号抵消与条件；若增加连续且非负，结论的依据改变。

方法：换元需要检查映射、微分和上下限；对称需要检查函数奇偶性和区间。模式从变化率/密度求总量，关联连续型随机变量的概率与期望，是应用边，不与全部概率知识串成强制单链。验收可让用户从速度图判断位移与路程所需积分，隐藏章节/方法名；只看算对一题不足以证明模型识别。

## C. 线性代数：特征值与特征向量

节点 eigenpair：Concept / Formula；A v=λv 是定义关系，v≠0，A 是指定数域上的方阵。前置：向量、矩阵作用、线性变换、齐次线性方程与核。求特征值的 det(A-λI)=0 来自非零核等价于奇异，是派生判据。实矩阵可有复特征值；二维旋转90度在实域没有实特征向量，但不能说在复域也没有。

几何直觉：非零v所张成的一维子空间在A作用下保持不变；λ<0可反向，λ=0映为零，不能笼统说箭头方向总不变。公式解释/非零条件 MUST_UNDERSTAND；推导行列式判据视前置选择 SHOULD_DERIVE；高次求根工具可 LOOKUP_OK。

模式：寻找保持的一维子空间、判断某v是否特征向量、计算特征对；策略可直接检查Av，或解特征方程后求核；不要所有题都先展开行列式。对角化还需要足够多线性无关特征向量，重根本身不能保证。

验收矩阵 A=[[1,1],[0,1]]：唯一特征值1，特征向量为(t,0),t≠0，只有一维特征空间，不能对角化。错误“v=0也是特征向量”先回到定义；错误“二重根所以两个独立特征向量”映射到核维数/代数与几何重数。闭卷解释不等于已能在陌生动态系统中识别该用特征分解。
