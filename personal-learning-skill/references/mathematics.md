# Mathematical Knowledge Modeling & Learning Layer

课程阶段与入口遵循 [学习生命周期](learning-lifecycle.md)：新整课先全景，续学恢复，明确题型总结直接交付；本文件提供当前分支细节。

仅在当前目标涉及数学概念、证明、定量模型或数学密集型学科学习时加载。普通英语/日语、代码语法、代码库入门保持原分支；学习机器学习中的数学时只对数学子任务启用。不按文件名或出现一个数字自动触发。

## 接入与节奏

复用主 Skill 的目标、来源、四图、概念卡、solve card、HTML、状态和复查。建/改数学节点或保存维度证据时读取 [节点格式](math-node-format.md)；需要设计例子或维护验收时读取 [三领域示例](math-examples.md)。不把示例中的教材位置或作答当用户事实。

本分支以一个连贯概念组为教学单元：直觉/问题 → 必要定义与条件 → 关键推导或动机 → 有理由的示例 → 少量集中检查。已有明确前置证据就直接讲授，不逐句要求确认；基础缺口或独立练习卡点才用最小提示。默认本次仅选择最能区分理解的任务，Teach-back、反例、识别可合并在同一题，不要求十二问、十维度和五阶段每轮全做。即时对话帮助不等待全书建图或课件制作。状态按原协议及时保存，但不让用户反复确认例行归档。

## A–E：教材到学习结构

A. **Source mapping**：先核验版本、目录、当前目标章节与页码口径。在既有 resources 索引记录章节/小节、定义、公式、定理、例题、习题的定位；标实际已读、待处理和无法核验。可先覆盖目标章节，后续增量读；扫描符号先核对，不能把目录当已读正文。
B. **Knowledge extraction**：把当前范围映射成稳定节点与多标签类型。章节只作来源；同概念跨章出现复用 ID。定义/定理/模型等以既有概念卡为正文，方法/题型复用 solve card；不复制教材整段。
C. **Dependency graph**：复用四视图、边表和既有节点；边标类型、方向、条件、来源/待核验。只补解释当前目标所需的联系，区分学习前置与数学推导，不把积分硬设成所有随机变量的前置。
D. **External prerequisites**：辨认书中省略的函数、求和、极限、组合、积分等；按当前任务分必需/有帮助/后续。只对影响当前任务且缺证据的前置短诊断，不强制补完另一门课。
E. **Learning path**：结合依赖、目标重要性、能力证据与可用时间选路径。考试频率必须来自实际考纲/试卷，未知不编造权重；改变教材顺序说明依赖理由。在 mission 的计划区保存路径和缺口，不再另建计划系统。

## 七类知识与学习任务

知识网络回答“连接什么”，knowledge_types 回答“是什么”；同节点可多标签。按重要性/类型/阶段选择以下内容，未适用省略，未知明确标记。

| 类型 | 必要教学焦点 |
| --- | --- |
| Concept | 是什么、为何需要、描述什么问题、最简例、反例及易混淆对象 |
| Property/Theorem | IF 假设 THEN 结论；直觉、证明思路、用法；条件是否必要须论证或反例，未知不断言 |
| Formula | 定义/推导/工具的角色；符号、定义域、适用条件、含义、依据及学习策略 |
| Mathematical Model | 现象/结构、假设、变量、参数、约束、数学表示、适用/失效条件和应用 |
| Method/Strategy | 触发线索、适用结构、为何有效、过程、易错点、关联模型 |
| Problem Pattern | 识别信号＋隐藏结构＋模型＋所需知识＋首选/备选策略＋陷阱和变式；不是答案模板 |
| Error Pattern | 真实首错→类别→原因假设→关联缺失节点→最小补救→针对练习→延迟再测 |

核心概念框架覆盖：是什么/为何需要/前置/联系/可推出什么/相关公式/有效条件/模型/触发问题/常错/脱稿解释/去章节提示识别。框架用于 agent 检查覆盖，不要求给学生机械输出全部栏目。

## 公式、模型与边界

公式沿“概念 → 关系 → 推导或动机 → 公式 → 条件 → 含义 → 应用”解释。定义型说明选择与意义，不强编定理证明；推导型回链依据；工具型强调选择条件。

为当前公式选择可组合标签并写理由：MUST_UNDERSTAND（含义与条件）、SHOULD_DERIVE（目标要求且前置足够）、SHOULD_MEMORIZE（高频/考试需要且有依据）、LOOKUP_OK（低频复杂或允许查表）。同一公式在不同课程可不同；同一使用场景不同时要求背诵又称完全不必记。提取/条件辨别/含义解释/误用检测/应用是可选测项，LOOKUP_OK 不按闭卷背不出判失败。

应用题先识别对象、变量、约束、假设、结构，再选择模型、求解和解释结果。可将这些决策合并为一次连贯解释，不拆成连环确认。未知假设标“题设不足/需条件化讨论”；自然语言中的“随机”不自动保证独立。比较相似模型，问为何适用及哪个条件变化会使当前依据失效；失效是无法按原条件保证，不必断言所有特殊情况绝不可能得到同一分布。

重要结论按需做去条件训练。Var(X+Y)=Var(X)+Var(Y)+2Cov(X,Y) 在二阶矩存在时成立；独立是协方差为零的充分条件，不能说只有独立才可相加。反例既可检验定理必要性，也可检验模型识别边界。边界判断同样需要用户证据。

## Recognition training：逐步撤去线索

按已有证据选择入口，可跳过重复阶段：1 已知知识＋直接例 → 2 已知知识＋变式 → 3 混合题 → 4 无章节标签 → 5 陌生情境。混合题也检查是否泄露方法，不把阶段编号当能力状态。

过程为题意 → 识别信号 → 问题结构 → 模型/相关知识 → 策略 → 计算或证明 → 验证。纯证明题没有合适的现实模型时可直接走结构与定理，不强填模型。

检查泄露位置：题面、标题、文件名、导航、提示按钮、相邻示例和答案区。去提示题用中性题号，教师分析与答案另放；刚讲完原模型的同类题只能记有上下文线索，不能算无提示迁移。只靠隐藏答案不是去除章节提示。记录显式模型/章节线索、提示使用及新情境，允许查表与自主选法分别记。

## 错误诊断与补救

根据实际过程定位第一处错误/无依据跳步。类别可多选：CONCEPT_ERROR、CONDITION_MISSED、MODEL_RECOGNITION_ERROR、FORMULA_MISUSE、STRATEGY_SELECTION_ERROR、DERIVATION_ERROR、CALCULATION_ERROR、REPRESENTATION_ERROR、PREREQUISITE_GAP、CARELESS_ERROR。CARELESS_ERROR 仅在用户能正确解释依据且有明确执行疏漏证据时使用，并写具体动作；证据不足标“待确认”，不把猜测写成能力事实。

先区分症状和原因：套错公式可能源于没认出模型，不必默认背诵不足。把首错映射到最小缺失节点，必要时用一个短任务区分竞争解释；给最小补救，再做针对变式及延迟再测。复用事件记录/solve card 和 REVIEWS，避免另造错题库或随机加十题。示例：互斥与独立混淆先回到交集与乘积判据，不先训练复杂概率计算。

## 按本轮目标选择输出

| 目标 | 本轮重点 |
| --- | --- |
| 首次学 | 概念、直觉、必要依赖；形成局部图 |
| 学公式 | 动机/推导、条件、含义和误用辨别 |
| 刷题 | 去线索识别、模型、策略选择 |
| 错题 | 首错、根因假设、最小补救与再测 |
| 复习 | 提取与混合识别，优先到期薄弱点 |
| 考前 | 有证据的重点题型、混练和高频个人错误；无考纲不冒充押题 |

Teach-back 可让学生脱稿解释关键条件、公式含义、模型假设和因果/推导关系；只纠正关键缺口。结束依照节点格式保存本轮实际测得维度，地图只更新相关边。掌握记忆、理解、推导、识别和迁移各有证据，某一维度成功不自动补全其他维度。
