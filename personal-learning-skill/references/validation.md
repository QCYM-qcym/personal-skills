# 首版验证记录

## 1.4.0 课程设计抽检（2026-09-20）

独立助手只读新规则并响应两个场景：条件概率学习者自述提示后仍不会，回复先保留能力未验证、降低负担并给诊断题；只读入门登录代码路径但尚无代码，回复索取材料并明确路径只是待核验框架，没有实施修改或虚构代码。检查了 HTML 结果需交回而非自动存状态、新旧 mission/resources 指针与正文的单一来源规则；据此澄清旧 NOTES 可以作为显式映射的唯一状态文件，不能与 CURRENT 双写。

两份 Skill 元数据、文件引用、协议分发一致性及现有六项检查通过。本轮修改的是学习规则与模板，没有生成具体课程 HTML；课件布局/交互、真实代码库入门和长期难度校准未实测，不据此宣称学习效果改善。

## 1.3.0 有状态协议试用（2026-09-20）

独立助手在隔离的虚构概率论目录实际创建状态文件，依次执行：讲解并出题、用户写错条件方向、给 L1 提示、用户要求暂停。修订号从 0 到 3；另一次进程读取文件后，可恢复课程身份、准确待答问题、L1 提示和暂停前活动。没有用户修正答案，节点仍为待学，次日任务仍待做，没有虚构掌握或提醒。

试用发现暂停事件被误填为 NODES 的最近能力证据，不能直接定位原作答。协议据此明确区分“最近事件”与“最近作答证据”；通过新增 revision 4 修正事件处理并再次读回，能直接定位原作答，保留原试验记录，不改写历史。另明确活动选择与次日续学/独立复查的区别。轻量版检查了协议兼容性，未单独跑写入场景。

静态检查覆盖两种 Skill 的元数据、引用、可独立分发的协议与模板一致性；`.learning/` 已确认被 Git 忽略。此次不是跨模型稳定性或多日学习试验；并发写入、设备同步、磁盘中断恢复和旧项目迁移规则尚未进行故障注入实测。协议不提供数据库级事务或后台自动记忆。

对当前磁盘 1.1.0 作备份后增量更新，保留跨学科、Teach、完整教学单元与迁移约定。静态审阅覆盖：概念优先而非全课学完才应用；详情卡与六项学习记录区分；华为笔记主用而非强制安装平板 Obsidian；PDF 为快照而非双向知识图；相对引用和版本元数据。包装时验证 YAML、文件引用与 ZIP 内容。此次没有重跑旧版独立助手场景，旧结果仅代表原测试版本；未进行华为设备导入导出或多日学习效果实测。

## 1.1.0 跨项目更新验证（2026-09-20）

本轮用独立助手对同三种输入分别加载更新前后技能并实际生成回复；另结合真实概率论会话中“反复碎问”的用户反馈。不是多模型试验或长期学习效果证明。

| 场景 | 更新前实际表现 | 更新后实际表现 |
| --- | --- | --- |
| 四周职场英语、仅文字、无Teach及文件工具 | 能开课，但只有“记录先留在对话里”，无完整接续包 | 交付目标、设置、来源状态、当前题与证据、复查的接续包；明确文字不能测听说 |
| 日语学习者反馈逐字追问过碎 | “这轮改成先完整讲解”，长期节奏未接续 | “以后按完整解释→一组练习→集中反馈”，给完整假名用途说明与分类任务 |
| Python代码来自粘贴，用户要求标掌握并继续 | 拒绝直接标掌握，但坚持先通过再继续 | 保留“参照代码完成、独立待验证”，尊重先继续选择并给新任务，不提供待做题代码 |

更新前英语原句：“记录先留在对话里，无需 Teach。”更新后：“请保存接续包，下次粘贴：目标＝四周独立写邮件……记录＝暂无独立证据”。更新前日语：“这轮改成先完整讲解”；更新后：“以后按‘完整解释→一组练习→集中反馈’推进”。

局限：每场景只抽检一次更新前后回复，并非五次重复稳定性实验；短回复中的地图只有导航规模。日语发音、实际英语听说、编程运行及云端产品的安装均未实测。不声称教学效果已验证或已安装到其他项目。现有通过的提示边界和掌握证据规则保持。

日期：2026-09-20。范围：一次无 Skill 基线（3 场景）、一次独立助手加载 Skill 后试用（同 3 场景），以及 3 个边界场景。以下是行为抽检，不是长期学习效果实验，也不是多模型稳定性测试。

## 基线与加载后的差别

| 场景 | 无 Skill 的实际表现 | 加载 Skill 后的实际表现 | 判定 |
| --- | --- | --- | --- |
| 只有概率论目录、无 PDF、20 分钟 | 直接分配时间并用骰子开课，未先建立知识视图 | 标明来源局限，给四张粗图、载体表和事件诊断题 | 修复了本次观察到的跳过建模 |
| 把两个相反方向的条件概率写成相等 | 已解释分母不同，并给百人模型和两步计算任务 | 指出错误等式，只问两种写法各把什么当已知条件，等待回复 | 本轮提示更小，未泄露数值答案 |
| 同类题连对后记笔记 | 已建议变式、混合和延迟验证，但笔记只有三项 | 区分用户报告与实际证据，给六项记录、复查及待补内容 | 保留原有有效建议并补齐记录规范 |

基线 A 原句：“今天先用20分钟学‘事件与概率’……前5分钟看例子，接着10分钟练习，最后5分钟回顾。”
加载后 A 原句：“四张小图（所有连线均为通用补充）”。
加载后 B 原句：“P(A|B)和P(B|A)分别把哪个事件当作已知条件？”

## 边界场景

- 无附件却要求“这本书第20页定理”：助手明确无法确认，询问页码口径，只给通用临时图；未声称读过教材。
- 明确只在本轮索要原题完整讲解：助手切换本轮模式，计算交集 0.16、条件概率 0.32，保留以后的提示偏好并给新变式。
- 仅要求翻译随机变量定义：助手只给译文，未强制开启学习流程。

## 已知局限与后续检查

尚无真实教材 PDF，也未进行真实用户的多日学习；OCR、具体教材知识图的正确性和实际复习效果都未实测。本次测试只能说明这些输入下的回复符合预期。下一步用用户自己的教材与学习记录检验，再按 iteration.md 小步更新。
