# 学科建模与载体选择

用于首次建模、扩展节点或更换教材。先做粗图，学习到哪里再展开哪里。四图共享节点 ID，避免同一个概念出现几个互不相连的版本。

## 四张图如何制作

| 视图 | 要回答的问题 | 制作方式与完成标准 |
| --- | --- | --- |
| 知识全景 | 学科研究什么、分成哪些模块？ | 以研究问题为根，模块为一级分支，附推荐学习路径。章节与模块建立对应，不照搬目录当作全部结构。 |
| 前置依赖 | 学这一点必须先会什么？ | 从前置指向目标，标“必需/有帮助/后续选修”以及使用场景；给必需前置一个诊断任务。 |
| 知识关系 | 概念如何定义、推导、比较、推广？ | 节点间使用有标签的边，至少展开当前核心的实际关系；等价、特殊情况和推导标适用条件。 |
| 跨学科连接 | 外部知识为什么与此有关？ | 写“本学科节点 → 具体用途/机制 → 外部概念”，标入口门槛；当前目标无关的延伸留待以后。 |

思维导图适合层级；知识图谱适合多对多。可输出 Markdown 树、边表或 Mermaid；没有绘图工具时这些仍是有效交付，不能只说“建议你画图”。大图拆成模块并保留跨模块引用。

节点最小记录：`ID｜名称｜来源（章节/书内页/PDF页或通用补充）｜掌握状态｜证据`。
边最小记录：`起点｜关系｜终点｜适用条件或具体用途｜来源/待核验`。
关系词优先用：前置于、定义、推出、等价于、易混淆、特例、推广到、应用于。`相关`太泛时补一句关系解释。类比不标成推导，应用不标成必需前置。

## 内容载体分配

| 内容 | 主载体 | 保留什么 |
| --- | --- | --- |
| 章节模块、分类、概念层级 | 思维导图 | 位置与层级，不塞长段落 |
| 前置、多重联系、对比、推广与跨学科 | 知识图谱 | 有意义的边、条件、来源 |
| 证明、计算链、算法成立理由 | 推导笔记 | 要解决的问题、关键依据与转折；完整内容定位回教材 |
| 建模、选方法、识别题意 | 例题笔记 | 决策点、适用信号、替代策略为什么不合适 |
| 用户的实际错误 | 错题笔记 | 首错与修正动作、关联节点、可验证的复查任务 |

同一内容可“图上一个节点 + 笔记一处关键推导”，两处互链。三类笔记统一使用六项记录格式；尚无错误填“未观察到”，不要制造错因。

## 概率论示例：通用演示，非用户教材摘录

以下不对应任何已上传 PDF，也不代表所有概率论教材都有这些章节。数理统计是相邻领域，只有教材或学习目标包含时才纳入主线。

**1. 全景图：**

```text
如何描述并推断随机现象？
├─ P01 事件与概率：样本空间、事件、公理、条件概率
├─ P02 随机变量与分布：离散、连续、分布函数
├─ P03 联合结构：联合、边缘、条件分布与独立性
├─ P04 数字特征：期望、方差、协方差
└─ P05 极限规律：大数定律、中心极限定理
推荐入口：事件与概率；P02 支撑 P03/P04，P04 支撑理解 P05 的常见表述。
```

**2. 前置依赖图：**

```text
集合交并补 ──必需：表达事件──→ P01
排列组合 ──按需：有限等可能计数──→ 古典概型
求和 ──必需：离散情形计算──→ P04
积分 ──必需：用密度求概率与期望──→ P02/P04 的连续情形
极限 ──必需：理解收敛表述──→ P05
线性代数 ──后续扩展──→ 协方差矩阵（不是入门全部内容的前提）
```

**3. 以 C01 条件概率为中心的关系图：**

```text
事件交集与概率 ──前置于──→ C01 条件概率
C01 ──按定义变形，分母事件概率>0──→ 乘法公式
乘法公式 ──结合完备事件组──→ 全概率公式
C01/乘法公式 ──同一交集的两种分解──→ 贝叶斯公式
C01 ──比较条件化前后概率──→ 独立性
C01 ──有限/离散情形的推广──→ 条件分布
```

边界说明：事件独立的一般判据为 P(A∩B)=P(A)P(B)。P(A|B)=P(A) 的写法要求 P(B)>0；不能把它无条件替代一般定义。连续情形按 X=x 条件化涉及额外定义，不能直接除以零概率。

**4. 跨学科连接图：**

```text
贝叶斯公式 ──先验结合观测更新──→ 统计学：贝叶斯推断
贝叶斯推断 ──以类别为假设──→ 机器学习：概率分类
期望 ──平均负对数概率（离散情形）──→ 信息论：熵
协方差矩阵 ──特征方向（需线性代数）──→ 数据分析：主成分分析
```

**网状展开与载体决定：**C01 的前置是事件交集；核心是条件改变后的概率；相关概念是独立性和条件方向；派生是乘法公式与贝叶斯公式；应用是不放回抽样；跨学科是贝叶斯推断。以上放图谱；贝叶斯公式的关键变形放推导卡；抽样时如何选条件放例题卡；实际出现的方向颠倒放错题卡。

**辅导示例：**用户写“P(A|B)=P(B|A)，因为都是同时发生”。先定位这处等式及理由，给 L1：“两种写法分别把哪一个事件当作已知条件？”然后等待。不要在同一回复中追加代入、数值答案和完整提示链。
