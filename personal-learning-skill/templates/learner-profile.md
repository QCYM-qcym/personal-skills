# 个人学习设置

将此模板复制到自己的学习目录后填写；未填项从当前对话推断并标为临时假设。用户可直接编辑此文件，不需要编程。此处是默认参数的唯一来源。

| 设置 | 初始值或填写说明 |
| --- | --- |
| 学科与材料 | 未提供；填写书名、版本、文件与目标范围 |
| 项目标识与模式 | 新学科/同项目接续；能力证据不跨学科复制 |
| 学科验收 | 英语/日语按目标选择理解或表达；编程独立编写、运行与解释；数学选法与推理 |
| 学习目标 | 未提供；改成可展示的能力及验收任务 |
| 已有基础 | 未诊断；不要自动按零基础或熟练处理 |
| 截止时间/每次可用时间 | 未提供；仅在影响安排时询问 |
| 语言 | 中文 |
| 短输入 | 起点为一个小节或约 5–10 分钟，按难度缩短 |
| 节奏模式 | 标准；可改快速/深挖，模式不代表能力等级 |
| 教学风格 | 默认清晰连贯；用户指定素材时记录来源/范围、组织与反馈偏好，可关闭，不另建档案 |
| 讲解节奏 | 先直觉或情境，再规则与有理由的例子，再少量集中练习；卡住才拆小，不反复确认已答对内容 |
| 当前挑战与支架 | 根据诊断暂定；记录独立能力、有限提示可达范围及下一次调整理由，不设固定正确率 |
| 正式课程载体 | lessons/HTML：交互、图解、测验；Markdown：概念索引与学习记录 |
| 初始地图规模 | 每图约 5–9 个主要节点，可按材料增减 |
| 提示方式 | 每次一个最小提示，等待尝试再升级 |
| 答案方式 | 默认引导；明确请求完整讲解时本轮切换 |
| 混合练习 | 起点为本轮节点加 1–2 个旧节点 |
| 复习间隔 | 首次学习后约 1、3、7、14 天；按真实表现调整 |
| 掌握证据 | 即时独立解释并通过变式；至少一次延迟闭卷验证后再标延迟通过 |
| 输出格式 | Markdown 树/边表；需要时用 Mermaid |
| 知识组织 | 全景→模块关系→概念详情；四图共享节点；默认先概念后集中归纳方法 |
| 平板与手写软件 | 用户使用华为平板自带笔记 App；具体机型、系统与 App 版本待确认 |
| 电脑/平板衔接 | 华为笔记为手写主工作区，Obsidian 为导航与关联媒介；优先学习页文件往返，传输方式与格式按设备核验 |
| 手写任务 | 解释、推导、闭卷重建、独立尝试与订正；不要求誊抄参考卡 |
| 保存位置 | 未指定时先在对话中交付 |
| 记忆位置 | 目标、来源、当前接续、能力证据；沿用用户本项目指定目录 |
| 笔记位置 | 导航、知识图、六项笔记、课件；可与记忆同目录或分开 |
| 宿主能力 | 本地文件/下载产物/仅对话；按实际能力填写，不假定能访问另一台设备的路径 |
| Teach 组合 | 可独立用本技能；用户指定且可访问时读取 Teach，记录实际来源 |

这些时长、节点数和间隔是可试用的安排，不是固定科学最优值。考试期限、负担和实际提取表现优先。
