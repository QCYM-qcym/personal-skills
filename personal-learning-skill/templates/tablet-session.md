# 平板学习页模板

生成时按屏幕或页面分区，给每题留足手写空间。参考内容与原题答案分开，不把长篇讲义塞进练习区。

- 日期 / 单元 / 节点 ID / 资料版本：
- 参考概念卡位置（先阅读，练习时关闭）：
- 本轮目标与验收标准：

## 1. 用自己的话解释

为什么需要这个概念？关键条件是什么？给一个例子或反例并说明理由。

手写区：

## 2. 闭卷重建关系

画出当前节点的一条依据/推导链，并与一个相邻概念比较；在线上写明关系与条件。想不起的地方先留问号。

手写区：

## 3. 独立尝试

填写本轮实际题目。基础阶段用辨析或简单应用，方法阶段再用跨题面变式。写关键步骤与理由。

手写区：

## 4. 对照后订正

首处不同 / 错因 / 关键依据 / 下次动作。把独立作答和看过提示后的订正分开标记。

## 5. 回流索引

用时（学习、整理传输分别记）/ 最高提示级别 / 手写附件位置 / 待复查任务与日期。只将有价值的变化更新回六项笔记和现有接续记录。
