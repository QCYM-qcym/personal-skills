# Solve card：解决问题卡

- 卡片 ID / 关联节点 / 题目或代码来源与版本：
- 问题：我要解释、求解或修复什么？
- 错因：实际首错与证据；无错误则写未观察到。
- 关键依据：适用条件、共同结构、相关定义/定理或已读代码路径。
- 修正策略：为什么选这个方法；必要步骤；何种情况需要换方法。
- 关联节点：纵向依据和横向对比，链接概念卡或真实代码位置。
- 复查任务：一个改变情境/条件的独立任务、验收标准与日期/触发条件。

尚在独立尝试时只记录已发生过程，提示按需给出；方法总结在概念理解后完善。完整题解或代码 diff 链接到原位置，不重复抄进卡片。

数学任务按 [数学层](../references/mathematics.md) 补充识别信号、隐藏结构、模型假设、首选/备选策略及变式。真实错误回链缺失节点与再测；示例陷阱不算用户已犯错误。独立识别题与教师分析分开，题目页不露出方法标签。

题型图复用本卡：按需补识别信号、隐藏结构、模型（适用时）、假设、首选/备选策略、陷阱、常错、变式与迁移情境。误解关联引用真实事件或明确标通用；不要把完整答案暴露给当前无提示评估题。
