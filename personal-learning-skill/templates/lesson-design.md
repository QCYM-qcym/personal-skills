# 单课设计模板（生成 HTML 前填写）

- 课次 ID / 内容版本 / 关联节点 / 前课链接：
- 诊断依据：用户实际表现、提示级别、自述与仍未知之处。
- 本课目标：一个可独立展示的动作。
- 难度假设：已经能做的、需要有限帮助的、暂时不引入的。
- 连贯讲解：直觉或情境 → 定义/规则与条件 → 有理由的示例。
- 图解：说明哪条关系或过程；对应文字解释。
- 交互：用户改变/选择什么，观察什么，用于检验哪一理解；无需交互时注明理由。
- 独立任务与验收：实际题目、反馈规则、开放回答的检查方法。
- 支架：逐级提示；何时撤除或改用完整前置示例。
- 结果交接：用户输入、提示使用、答案展开、结果与时间如何复制给 agent。
- 来源：教材定位或代码提交、文件与符号。
- 导航：mission、概念卡、solve card、notes 的实际相对链接。
- 验证：窄屏/普通屏幕、键盘、图解、提交反馈、提示、复制结果、无网络可用性；未实测项如实列出。

这是设计模板，不是已生成 HTML。生成后另保存到 lessons/，不把此 Markdown 改名为 .html。

数学课按 [数学层](../references/mathematics.md) 选择当前 session goal；题面、标题、导航与相邻示例检查方法线索，结果交接附 cue_level 和实际测项。集中检查可为同一目标的一小组题，记录各题提示情况，不机械展示全类型/全维度。
