# 学习记录模板

按需复制相关部分，不要求每轮重填整页。真实尝试与计划分开；未知填“待确认”。

## 本轮导航

- 日期、材料版本与已读范围：
- 本轮可检验目标：
- 当前节点 ID、名称、来源位置：
- 必要前置与诊断结果：
- 关联节点：前置 / 相关 / 派生 / 应用 / 跨学科（无可靠连接时说明）：

## 六项笔记卡

| 字段 | 记录内容 |
| --- | --- |
| 问题 | 一个疑点、回忆问题或实际题目；标记推导/例题/错题 |
| 错因 | 用户首错原文、证据和分类；尚未观察到则注明 |
| 关键依据 | 条件、定义或关键转折，附教材定位 |
| 修正策略 | 下次可以执行的一个动作 |
| 关联节点 | 节点 ID 与关系，不只写章节名 |
| 复查任务 | 何时/触发条件、闭卷任务、通过标准 |

## 验证与接续

| 日期 | 节点 ID | 任务类型与内容 | 用户表现证据 | 最高提示级别 | 状态/下一次复查 |
| --- | --- | --- | --- | --- | --- |

任务类型可用：主动回忆、首次尝试、变式、混合、延迟闭卷。计划中的任务不填写“通过”。
跨会话接续时带上：当前节点、尚未解决的首错、最后提示级别、待答问题、下一次复查。
