# 能力地图与适用边界

这是针对用户图片与目标整理的训练分类，不是公认的唯一能力分类或心理测量量表。图片将通用动作、数学工具和物理方法混排；标题写“16种”，可见左表实际列出17项，不据此固定课程数量。

## 八组可观察动作

| ID / 能力组 | 训练动作与验收依据 | 图片中的入口 |
| --- | --- | --- |
| T1 观察与提问 | 分开事实与解释；明确可观察变量、单位和可检验问题 | 观察、发现规律 |
| T2 归纳与分类 | 按明确标准分组；从样本提出猜想并主动寻找反例 | 归纳、分类 |
| T3 抽象与建模 | 确定对象、变量、关系、假设与忽略项；给出模型预测和边界 | 概括、理想化模型、方程、函数、待定系数 |
| T4 转换与分解 | 将问题拆成子问题或换表示；说明转换保留什么、是否可逆 | 化归、分解、等效替代、换元、配方、面积变换、数形结合、图像 |
| T5 不变量与对称 | 指定变换与保持量；区分不变、协变和仅形式相似 | 平移旋转、对称、变中找定 |
| T6 特殊化与推广 | 用简单/极端情形探路；提出推广并检验条件；建立结构类比 | 特殊化、一般化、极限思想、类比 |
| T7 逻辑与论证 | 明确前提和结论、必要与充分；检验反例，给出有效推理 | 反证、逆向思维；方程中的条件推理 |
| T8 实验与证据 | 比较竞争解释；设计测量与对照；识别混杂、误差及不确定性，按结果修正 | 控制变量；补充数据与证据评价 |

按实际任务组合，例如观察 → 建模 → 转换 → 推导 → 实验检验 → 修正；数学任务可能转向证明与反例。先解释核心知识，再归纳方法和二级结论。

## 不应合并的概念

- 类比比较不同对象的结构，归纳从实例形成概括；二者都可能产生猜想，均不能单独证明普遍结论。
- 控制变量用于分离影响因素；特殊化是选一个特例。实验比较还需要考虑混杂、重复测量、测量误差及适当对照，不能只喊“其他不变”。
- 逆向分析可从目标追找充分条件；反证是假设结论不成立并推出矛盾。回到正向时检查步骤是否成立，避免把必要条件当充分条件。
- 对称首先是对象/规律在指定变换下的性质；是否减少计算需具体判断。不能把所有对称都说成守恒定律。
- 换元、配方、待定系数和面积方法是工具。训练重点是选择线索、取值限制、保留结构和适用范围；名称熟悉不等于会用。
- 拟合数据不自动识别唯一机制；量纲一致是必要检查之一，不足以确定物理定律。理想化模型能解释部分现象，也有失效尺度。

## 选题示例（教学设计，不是用户证据）

| 情境 | 初始任务 | 变式/迁移检验 |
| --- | --- | --- |
| 数学规律 | 教学合成数据 x=1,2,3 时 y=1,4,9，能否唯一确定函数？请给理由 | 限制为次数不超过2的多项式时，判断哪些结论改变；看似相同数据不等于唯一规律 |
| 力学建模 | 比较“忽略空气阻力”与“考虑阻力”的落体模型，写假设与可观察差别 | 改变物体形状后先预测模型适用性；使用资料/仿真，不安排高处投掷 |
| 生物实验 | 两盆植物同时改变光照和浇水，生长不同，能否判断光照作用？ | 设计可区分解释的比较，说明个体差异和重复样本；不提供待答原题的完整方案 |
| 化学表征 | 根据已学粒子概念，用文字、粒子图与符号描述同一变化 | 区分模型中粒子数与宏观物质的量；缺前置先补，不让形式变换取代化学含义 |
| 日常判断 | 学习时间增加后成绩提高，提出可能解释与缺失证据 | 比较难度、睡眠与练习类型等因素；这只是该情境表现，不宣称全面决策能力提高 |
