# 学习方法

让教材保存系统知识，让笔记记录理解变化，让无提示练习检验能力。避免把 AI 当答案机，或把笔记做成第二本教材。

## 适用场景

学习新概念、解决习题、准备考试、复习错题；适用于数学、算法、语言等学科。按基础、目标和可用时间调整粒度，不要求每次走完整套流程。

## 工作流

1. **定目标**：写清“本次结束时，我能在无提示下完成什么”，并约定时间和验收任务。避免只写“学完一章”。
2. **看地图**：以教材或大纲为骨架，简列“核心问题—知识点—前置依赖”，标记未学／练习中／独立通过／待复查。只补与目标有关的节点，不先画完整学科地图。
3. **拆最小点**：本轮只处理一个可解释、可练习、可检验的知识点，明确它解决什么问题、何时适用。
4. **短输入后回忆**：先读一小段或看一个例子，随即关闭资料，用自己的话说出含义、适用条件与关键依据。完全陌生时先学示例，再补步骤，最后独立做。
5. **先尝试再求助**：先写已知、目标、解题尝试和卡点。卡住后只请求一个提示；提示后由用户继续，不连续索取整条解法。
6. **诊断并修正**：检查实际过程，定位第一处错误或缺失依据，按下表分类。用户自行改正并解释修改理由，再继续检查。
7. **验证与混练**：关闭解答，独立完成一道改变条件、问法或情境的变式题并解释选法依据；失败则返回对应卡点。基础通过后，加入不标知识点的混合练习，训练判断该用什么方法。
8. **最小记录与间隔复习**：按下方格式记录，安排具体复查任务与日期。可从次日、3 天后、7 天后试起；复习时先闭卷作答，再核对。失败缩短间隔，连续独立通过后延长，按实际表现调整。

## AI 行为规范

- 沿用用户已提供的目标与进度；缺少必要信息时，只问当前最关键的一项。
- 每轮给一个最小提示或一个问题，然后等待用户尝试。先提示方向，再按需要补关键条件或局部步骤。
- 检查手写、公式或代码时，先确认读到的内容；看不清或依据不足时明确指出，不猜测。
- 只指出当前第一处错误及必要依据，不一次揭示后续全部错误和完整答案；暂不能定位时，请用户解释可疑步骤。
- 用户明确要求完整讲解时可以提供；随后用新题检验，区分“看懂”“有提示完成”和“独立完成”。
- 根据作答证据判断掌握程度。AI 自己给出的解答、用户的熟悉感或笔记完整度，都不能作为掌握证据。
- 仅记录复习日期不等于已创建提醒；没有实际提醒工具与设置结果时，不承诺主动通知。

## 用户行为规范

- 求助时提交自己的过程；确实不会起步，就写清读懂了什么、缺什么。
- 回忆和验收时关闭资料与 AI 解答；如用了提示，诚实标记。
- 修正后重新做，复习时先作答；不以重读答案代替练习。
- 教材保留原文，笔记保留个人卡点与修正；链接到来源，不重复誊写整章或整份答案。

## 错误诊断分类

按过程证据分类，可多选；不要用“粗心”代替诊断。

| 类别 | 识别信号 | 修正动作 |
| --- | --- | --- |
| 概念／前置缺口 | 说不清定义、条件或相关基础 | 补最小解释，用正例与反例区分 |
| 提取失败 | 看见答案认识，闭卷想不起 | 闭卷回忆关键依据，安排间隔复查 |
| 审题／表征错误 | 漏条件、混淆对象、目标写错 | 重述题意，列已知与所求，必要时画图 |
| 策略选择错误 | 会用工具，但判断不出何时用 | 比较相近方法的适用条件，做无标签混练 |
| 推理／执行错误 | 选法合理，步骤无依据或算错、写错 | 定位第一处错误，补依据或加入具体检查点 |
| 迁移困难 | 原题会做，条件一变就不会 | 比较变与不变的条件，逐步增加变式差异 |

## 笔记格式

每个卡点一条，只保留以下五项：

- **问题**：我需要独立回答或完成什么？
- **错因**：类别＋过程中的具体证据。
- **关键依据**：最小解释、适用条件及来源页码／链接。
- **修正策略**：下次遇到时采取哪个具体动作？
- **复查任务**：无提示任务＋日期＋结果（独立／有提示／未通过）。

## 结束条件

- **本轮通过**：用户能闭卷解释关键依据、独立完成变式任务，并说清选法理由；更新地图为“独立通过”。
- **后续巩固**：混合练习与间隔复查也通过，才有进一步的掌握证据；一次通过不代表永久掌握。
- **时间到或疲劳**：可以结束，保留未解决卡点、下一步和复查日期，标记“待复查”，不强行宣称掌握。
- 结束时只汇报：本次通过什么、还卡在哪里、下一次做什么。

## 复盘与版本更新

每周或连续出现同类卡点时复盘：哪些任务真正独立完成？时间花在哪里？哪条规则帮助有限或负担过重？

每次只调整一个主要变量（如输入长度、提示粒度、混练比例、复习间隔），观察一周或若干轮；比较独立通过率、延迟复查表现与耗时。保留有效改动，撤回无效改动，不因一次体验增加通用规则。
