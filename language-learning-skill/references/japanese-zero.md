# 日语零基础路径

目标先按生活交流暂定；用户有留学/JLPT/工作等目标再调整。不把零基础直接等同于某考试等级，也不把JLPT阅读成绩当口语能力。

## 主线与里程碑

用户有教材先沿用。无教材可采用日本国际交流基金《いろどり》入门的情境和音频资源作为主线，按实际读取章节记录来源，不声称已读全书。官方提供入门课程材料与音频；本路线是本项目的安排，不是官方达标承诺。

1. **声音、文字和第一句交流并行**：先从当前表达涉及的少量平假名及基本声音开始，配合问候/姓名介绍；片假名逐步连到姓名及外来词。无需背完五十音才开口。
2. **建立声音区别与识读**：清浊音、半浊音、拗音、促音、长音、拨音按任务展开，区别按拍计时与汉语音节。听辨/朗读需音频，不用汉字谐音当标准发音；罗马字仅临时支架，逐步撤去。
3. **常见句型和互动**：身份、所属、地点、数量/时间、喜欢与日常活动；助词、动词变化、否定/过去在表达中引入，再总结。礼貌体与普通体注明情境，学习者不必先背全套活用表。
4. **短对话与理解**：购物、问路、日程等情境，练回应和请求澄清；换对象/信息后独立完成，不只是朗读原文。
5. **读写扩展**：短消息/告示和常见汉字词；汉字词的读音、用法与语境一同学，避免把中文熟悉感当日语理解。

每个里程碑用新情境的实际表现验收，听辨和表达不足留待测。不能按上了几课自动判等级；如目标改为JLPT，核验官网题型与要求再制定考试路径。

## 第一课示例（原创，不是用户已学记录）

目标：能用简短礼貌句介绍自己并询问姓名。解释「わたしは…です」与「お名前は？」的场景及礼貌差异，说明助词は在此读わ（wa）；提供如「はじめまして。リンです。よろしくお願いします。」的完整示例。零基础必要时加读音支架，替换姓名做一次集中尝试；没有音频只验文字表达，不评发音。用虚构名字即可，不要求真实身份信息。

地图：自我介绍 → 姓名词块/礼貌结尾；文字图连接は的字形与助词读法。学生只手写自己的版本与一个疑点，不抄整段讲义。

## 常见诊断

长短音/促音混淆先核验音频与实际反应；助词误用先检查意图和句中关系；用中文词义硬套日语时比较真实例句；会背句子不会换信息则练受控替换再自由产出。不以一次错误给“语言天赋差”的标签。
