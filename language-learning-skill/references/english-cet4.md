# 英语基础提升与CET-4路径

默认目标是大学英语四级CET-4，不是英语专业四级TEM-4。先区分达到相应读写听力能力还是准备具体考试；有考试计划再问日期/目标，报名资格与当次安排需核验当地学校和官方通知，不保证可以报名。

## 低负担诊断

已提供近期成绩、原稿、试题和录音时先用已有证据。否则给一个短阅读任务（主旨/细节/关键句理解）＋一段实际写作或翻译；听力在音频可用时单独测，词汇和语法从真实卡点抽查。无需先做完整模拟卷才开课。全部标明自编诊断而非真题，不由一题或自述词汇量估算总分。

只提供文字时可诊断阅读/写作/翻译；“听力较弱”先作为用户自述，未测则不评分。短诊断后输出已见证据、主要缺口、下一单元理由和临时路径，缺项随后补。

## 分阶段训练

- **补当前基础**：在阅读和表达中补高频词块、句子主干、从句关系、时态与搭配；记词同时学意义、搭配和提取用法，不先要求刷完一本词汇书。
- **分项技能**：听力主旨/细节及转折；阅读定位、推断与长句处理；写作任务回应、组织、论据和语言；翻译信息完整、句法重组与准确表达。先示范再变式，答案依据指向材料。
- **限时与混合**：基础能推进后加入题型、时间分配和混合练习。测得条件、播放次数、查词/提示和是否做过原题明确；重复真题成绩不当陌生水平。
- **阶段复核**：用新材料和不同日期证据判断薄弱项是否改善；近考时使用可靠来源的完整试卷和音频检验时间管理。人工/AI作文评分仅作练习反馈，注明标准和不确定性，不保证正式成绩。

## 官方结构快照

2026-09-23核验 [教育考试院CET笔试介绍](https://cet.neea.edu.cn/html1/folder/16113/1586-1.htm)：写作15%/30分钟，听力35%/25分钟，阅读35%/40分钟，翻译15%/30分钟，总计125分钟。听力含短篇新闻、长对话和听力篇章；阅读含选词填空、长篇匹配和仔细阅读。制定正式模拟安排前再次核验官网；口语考试是另一个目标，不能把笔试通过当口语通过。

总分不是把自编题正确率直接乘710。使用官方分数解释和实际量表，不擅自换算或将CET分数等同某个CEFR等级。用户以425为个人目标可以记录，但不要把它描述为官方统一合格线；需要解释分制时重新核验[官方分数说明](https://cet.neea.edu.cn/html1/folder/19081/5124-1.htm)。该官方页面本次已核验：报道总分710，采用常模参照且不设及格线；练习正确率不可直接换算正式报道分。

## 错误反馈和资源

阅读分词义、句法、逻辑、定位与推断；听力分声音识别、切分、词义、注意/信息保持，需实际音频表现判别。写作优先内容与组织再聚焦关键语言错误；翻译先查意义有无遗漏/反转，再调表达。不能把所有错误归于“词汇不足”，也不拿空泛万能模板代替切题表达。

优先用户合法提供的教材/历年题及官方大纲信息；只链接或提取必要片段，不将付费题库复制进公共Skill。无真题可原创同能力目标练习并注明自编，不能冒充某年真题。使用答案时遮挡独立题解，教师例子和验收题分开。
