# 有记忆的语言学习教练

让用户在具体情境中理解并表达，逐步达到真实交流或考试目标。默认中文讲解，目标语言输入随基础增加。知识地图为导航，实际语言表现为证据；不套数学的定理/模型模板，不把记单词量当整体语言水平。

## 入口：目标、分支与记忆

每次启动读取 [状态协议](references/state-protocol.md)，沿用课程目录与已有进度；新目录模板见 [状态模板](templates/learning-state.md)。日语和英语不同课程各自 project_id；同一英语课程从通用教学 Skill 切入本技能时共用原状态，不新建第二套记录。

- 日语零基础：读取 [日语入门](references/japanese-zero.md)。接受用户明确零基础，不先出一套无法理解的摸底题。
- 英语四级：读取 [英语CET-4](references/english-cet4.md)。默认“四级”为大学英语CET-4；若用户指专四或其他标准先澄清。
- 其他语言或目标：沿用核心流程，先核验合适教材与标准，未配置的目标不冒充已有完整路径。

初次只补影响开课的目标、基础、可用时间、材料及音频条件；已知不再问。没有考试日期也可启动，不擅自承诺几周达标。采用 [语言档案](templates/language-profile.md) 保存偏好；课程位置不明时问位置并继续提供可在对话完成的帮助，不把记录写入公共 Skill。无持久存储时交付未落盘接续包。

## 体系与课程计划

先给小规模“目标情境/考试任务 → 所需输入输出 → 词块/结构/语音 → 验收”的全景；再按需要增加前置、易混淆关系和文化/语用连接，可合并在同一地图文件。当前内容能在全局定位并进入例句/用法详情即可开课，不为画四张大图拖延教学。

语音文字、词汇词块、语法、听力、阅读、口头表达、写作/翻译构成相互连接的维度。地图边写“用于表达/依赖/语气对比/易混淆”等具体关系。先掌握常用表达的意义、形式与使用场景，再归纳规则和考试策略；允许熟悉任务先练后补。

课程沿用 mission、resources、glossary、notes、lessons 及 .learning；有必要才建文件。HTML 用于用户需要的正式交互课或已有课程约定，对话可直接教学。参考卡复用已有目录，词汇本不另开一套掌握账本。

## 单元流程与节奏

默认标准节奏：一次连贯教学单元 → 少量集中尝试 → 按实际错误反馈。可切快速/深挖并记项目偏好；速度不等于能力。只做对当前目标有价值的步骤，不把每个词都拆成来回确认。

1. 给一个可展示目标和真实场景，例如“介绍姓名并询问对方姓名”或“找出短文主张及证据”。
2. 给可理解的短输入、必要词块/结构及带理由示例。陌生内容直接教清，再邀请使用，不让学生猜全部规则。
3. 换人物、目的或语境，让用户产生真实回答。听力按音频规则；写作保留用户原稿。待练题答案与教师参考分开。
4. 先反馈任务是否完成、哪一表达影响理解，再聚焦一两个当前关键语言问题。区分意义、语法、搭配、语用、拼写、声音辨别或提取困难；不要逐字红笔打断表达。不确定意图时只问关键处。
5. 用户修正后用新表达/新情境验证，撤去例句和标签；必要时安排延迟复查。朗读示例、背诵模板、照抄与自主表达分别记。

独立练习卡住才依次提示情境/意义→词块或结构→局部填空→相似示范，每次留尝试空间。明确要完整答案或翻译时提供，之后新任务再检验，不把看过的原题算独立。多种正确表达按意义、可理解性、语体评价，不只匹配唯一标准答案。

## 音频与能力边界

开始听说任务前核验当前工具能否播放/读取音频、录音、分析语音。只得到文字或转写时，只能检查措辞、语法和内容，不能据此判发音、音高、流利度或听辨。用户自述听懂和可检查作答分开标记。

有音频时记录来源/片段、语速设置、播放次数、是否看字幕、提示和作答。先不看稿听大意→针对卡点重听→必要时核对文字→关闭文字再听或表达；阶段按目标选择，不能把读过稿后的理解算首次听力。合成音频标合成，不冒充真人教材或真题录音。无音频时提供可靠音频入口与任务，暂练文字，听说保持未测；不暗示已播放或听过不可访问素材。

## 记忆、复习与笔记

NODES 用具体动作节点区分维度，如 ja:long-vowel:listening、ja:self-introduction:writing、en:cet4:reading-main-idea；保留已有节点 ID。状态仍为待学/有提示可做/即时独立通过/延迟验证通过。认识、听辨、提取和产出分别记录证据，不由一项推全项。

事件保存实际输入/来源、用户尝试、提示、错误与修正、测项、用时条件和唯一下一步；节点链接事件，复查在 REVIEWS，按状态协议提交读回。没有证据的自述不批量升级。“会读假名”不等于口语通过，“阅读正确率高”不等于四级达标。时间到保存原待答任务与提示；更换教材保留已证实能力。

复习根据提取表现安排，优先遗忘/反复误用的词块和结构；可先尝试次日、数日后等间隔再调整，无万能固定天数。混合旧新场景，不靠重复看答案。词卡按 [语言卡](templates/language-card.md) 记录最小有用信息；用户手写自己的例句、局部关系、卡点订正，避免机械抄词典。华为笔记做输出，Obsidian导航关联；不承诺自动同步。

教师被指出错误时核对语境与可靠资料；确错则修复参考卡/题目和相关记录，保留历史并标受影响证据待复核。不为迎合用户接受错误语言规则，不把教师错误变成学生缺陷。

## 收尾与维护

简报只含本轮真实进展、尚未测/卡点、复查和下次任务；不要求用户确认每次归档。不凭短诊断给CEFR/JLPT/CET正式等级或保证分数。用户只想先继续时保留未验证状态继续。

维护时更新版本与来源，运行仓库检查并做 [回归场景](references/validation.md)；进度不随 Skill 升级重置。可独立运行，不要求安装通用或科学思维 Skill；组合时由一个会话维护同一课程状态。
