# 语言课程个人设置（保存在课程项目）

- 语言/目标：日语入门交流、英语CET-4或用户指定；考试与交流目标分开。
- 现有基础：自述与已检查证据分别写；未测不评等级。
- 时间：每次可用时间、频率、考试日期（未知可暂缺）。
- 主线材料：版本、章节、音频链接/时间段、实际已读范围。
- 音频条件：可播放/可读音频/可录音/仅文字；按实际能力。
- 节奏：标准（连贯教学＋集中检查），可改快速/深挖。
- 输入支架：中文解释、注音/罗马字/字幕的使用与撤除条件。
- 复习：按提取证据调整；未创建工具任务时不承诺自动提醒。
- 偏好与手写：华为笔记输出，Obsidian导航；不要抄整本教材。
- 状态与材料位置：同课程复用原目录；双语新课程分别project_id。

能力与证据只在NODES和事件，不在本设置重复维护。启动时缺信息只问当前关键项。
